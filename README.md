# NOVA MIND Global

Public website for the YouTube channel [NOVA MIND Global](https://www.youtube.com/@novamindglobal) (`@novamindglobal`).

This repository contains only the static site:

- `index.html`
- `privacy.html`
- `contact.html`
- `css/site.css`

It is not the video production project. It contains no OAuth secrets, tokens, or API keys.

GitHub Pages, when enabled for this repository, should publish the `main` branch from the repository root. The site address is `https://jeanpierre1991.github.io/nova-mind-global/`.
