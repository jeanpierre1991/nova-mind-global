Privacy

This page describes this website and the separate YouTube integration used by NOVA MIND Global. It states only practices that are already true.

Last updated 20 November 2026.

This website

These pages are static. They do not create accounts, do not include a form, do not run analytics, and do not include advertising. NOVA MIND does not set cookies from these pages.

The YouTube button is a normal link. The pages do not embed a YouTube player, so opening this site does not by itself contact YouTube. A request to YouTube starts only if you follow the link.

The site is prepared for GitHub Pages. When it is published there, GitHub serves the files and may keep technical hosting logs under the GitHub General Privacy Statement. This website does not receive a copy of those logs.

YouTube integration

Uploading a film is a separate local program. It is not part of this website. The program uses Google OAuth so a person who already controls the channel can send a video to NOVA MIND Global and read that upload’s status back.

The Google Cloud project for that client is nova-mind-youtube. The client is a desktop application. Its sign-in returns to the same computer through http://localhost. This website is not the OAuth redirect address.

The application is in Google’s Testing mode. This website does not change that setting.

OAuth permissions

The integration is built to request these two YouTube scopes:

  • https://www.googleapis.com/auth/youtube.upload — upload videos and manage YouTube videos on the authorized channel.
  • https://www.googleapis.com/auth/youtube.readonly — view YouTube account information. The program uses this to confirm that the signed-in channel is NOVA MIND Global and to read upload and processing status.

No other Google scope is part of this integration. It does not request Gmail, Drive, or YouTube Analytics.

Where credentials are stored

The OAuth client file and the refresh token are files on the operator’s own computer. They are not stored on this website and they are not placed in this public repository. File permissions limit those files to the operator’s account.

When the program needs to call YouTube, it asks Google for a short-lived access token and keeps that token in memory for the operation. The program does not write the access token to disk.

Revoking access

You can remove the application’s access at any time from the Google Account that granted it:

  • Open Google Account permissions.
  • Remove access for the NOVA MIND YouTube application.
  • Delete the refresh token stored on the operator’s computer so the program cannot present it again.

After revocation, Google rejects further token refresh until a person consents again. Removing access does not by itself delete videos already uploaded to the channel. Those remain under the channel’s YouTube settings.

Not yet confirmed

These items are not stated above because they are not confirmed:

  • A public contact email.
  • A postal address.
  • The legal name of the person or entity that operates the channel.
  • A custom domain. None is in use.
  • Any future OAuth scope beyond the two listed above.
